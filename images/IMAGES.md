# Image checklist

Every image on the site is a **placeholder** right now (a gray box with a label). Replace each file below with a real photo, using the **exact same file name and folder**. The code doesn't need to change.

**Where to get them:** [images.nasa.gov](https://images.nasa.gov) and [science.nasa.gov](https://science.nasa.gov). Most NASA images are public domain. Webb images come from [esawebb.org](https://esawebb.org) / [webbtelescope.org](https://webbtelescope.org).

**Before adding a photo:**
- Save it as `.jpg`, about 1200 px wide.
- Keep it under ~300 KB. You can compress it at [squoosh.app](https://squoosh.app).
- If the photo doesn't match the alt text below, update the `alt` and the caption in the HTML.
- File names are case-sensitive on GitHub Pages: `Mars-Globe.JPG` is not the same as `mars-globe.jpg`.
